Wispr Flow API Key Setup

Wispr Flow provides low-latency speech recognition through its developer Voice Interface API. You can enter an API key to route audio to the live endpoint, or use the built-in browser engine.

Keys are stored securely in your local browser storage (localStorage) and never transmitted to third parties.
How to get an API Key:

1. Sign in to your dashboard at wisprflow.ai.

2. Request developer Voice Interface access via wisprflow.ai/developers.

✓ If you don't have an API key, leave this empty. The app runs in Client Canto Engine Mode using your browser's microphone with simulated sub-200ms formatting!
